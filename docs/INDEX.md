# Documentation index

Tekken 3 (SLUS-00402) as recompiled by Tekken3Recompiled and extended by Tekken 3 Expanded.
Facts are marked **tested** (seen in game), **code** (read in source) or **inferred**.

- `vision.md` – direction of the project (layers: style, donors, own models...).
- `code-map.md` – what every file in `character-builder/` does and its key functions.

## knowledge/ (what we know)

- `character-ids.md` – stock character IDs, model numbers, guest IDs 23+.
- `roster-tables.md` – roster tables in Tekken3Recompiled, names on screen.
- `donors.md` – donor principle, style layer, donor tests (Ogre, Gon, Dr. B, True Ogre, Anna,
  Kuma), the ID 43 strip-tile bug and patch 8.
- `mokujin.md` – Mokujin's round-start draw and sword (patches 5, 6).
- `expanded.md` – Tekken 3 Expanded architecture (TTT1 roster, guests).
- `custom-page.md` – the CUSTOM page: customs.txt, sync, descriptors, move keys, tests.
- `models-costumes.md` – disc models/ARC textures, CLUTs, 3D preview, poses, palettes and colour
  variants (patch 9), clothing pieces.
- `own-models.md` – 3DMK format, own model file T3CM, in-game replacement (patch 10), FBX import
  results.
- `t3-model-style.md` – how Namco's fighter models are built (budget, quads, gouraud records,
  joints, textures, face) and how the importer applies it.
- `portraits.md` – portrait and name plate `.jui`.
- `moves.md` – move format.
- `testing.md` – Test button, report, helper scripts in `tools/`.
- `lessons.md` – mistakes not to repeat.

## plans/ (what is next)

- `direct-import.md` – PS1-style models imported as they are (current).
- `kitbash.md` – new fighters from Namco parts (dropped by the user).
- `later.md` – TTT1 styles as donors, open donor issues.
